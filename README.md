# BondAnalytics.App

Приложение для анализа портфеля облигаций с интеграцией Tinkoff Invest API.

## О проекте

BondAnalytics.App — это WPF-приложение на .NET 9 для анализа инвестиционного портфеля облигаций. Приложение подключается к брокерскому счёту Тинькофф через Tinkoff Invest API и предоставляет удобный интерфейс для отслеживания позиций, доходности и графиков купонных выплат.

## Основные возможности

- **Загрузка портфеля**: Автоматическая загрузка облигаций из брокерского счёта Тинькофф
- **Реальное время**: Подписка на потоковые котировки для актуальных цен
- **Фильтрация**: Фильтрация облигаций по типам (ОФЗ, корпоративные)
- **Аналитика**: Отображение ключевых метрик портфеля:
  - Текущая и средняя цена
  - Профит/убыток (с цветовой индикацией)
  - НКД по каждой позиции и полная стоимость с НКД
  - Текущая купонная доходность относительно рыночной цены
  - Даты ближайших купонов
- **Аналитика счёта**: Пополнения, выводы, сделки, чистые денежные потоки, прибыль и доходность за выбранный период
- **История стоимости**: График полной стоимости портфеля с отметками пополнений и выводов; снимки хранятся локально в SQLite
- **Результат продажи**: FIFO-сопоставление с покупками; отдельные суммы изменения цены и изменения цены вместе с полученными купонами по облигациям
- **План инвестиций**: Сценарий сложного процента, календарь и повышение взносов, купоны/реинвестирование, комиссия, налог, инфляция, цель и фактическое выполнение
- **Визуализация**: Семь встроенных графиков портфеля без отдельных окон
- **Статус API**: Постоянный индикатор связи и автоматическое переподключение с увеличивающимся интервалом при сбоях
- **Группировка**: Автоматическая группировка по типу облигаций

## Мобильное приложение Android

`BondAnalytics.Mobile` — отдельный .NET MAUI-клиент для телефона. Он повторно использует модели и бизнес-логику `BondAnalytics.Domain`, а также T-Invest API и SQLite-репозиторий из `BondAnalytics.Infrastructure`; WPF-приложение при этом не меняется.

- Пять мобильных разделов: портфель, обзор с семью типами графиков, аналитика счёта, инвестиционный план и настройки.
- Светлая и тёмная темы (тёмная по умолчанию), сортировка портфеля, цветовая индикация прибыли и убытка, купонные столбцы с разбиением по бумагам и прокручиваемый план с тремя кривыми и линией цели.
- При первом запуске приложение объясняет, как создать токен T-Invest только с правами чтения. Токен хранится через Android SecureStorage/Keystore и повторно не запрашивается; сброс доступен в настройках.
- История стоимости и сохранённый план находятся в локальной базе приложения. Сброс токена не удаляет эти данные. Карточка портфеля показывает изменение относительно последнего сохранённого значения за предыдущий день.
- Для графика стоимости в аналитике можно выбрать период аналитики, последние 30 или 90 дней либо год. На графике отображается не более одной (последней) точки стоимости за календарный день.
- Котировки обновляются потоком API раз в 15 секунд, а состав портфеля — вручную и каждые десять минут.

## Архитектура

Проект построен по принципам чистой архитектуры с разделением на три слоя:

```
BondAnalytics.App/           # Presentation layer (WPF + MVVM)
BondAnalytics.Domain/        # Domain layer (сущности, интерфейсы)
BondAnalytics.Infrastructure/ # Infrastructure (Tinkoff API, токены)
```

### Ключевые компоненты

- **Domain**:
  - `PortfolioItem` — модель позиции в портфеле
  - `PortfolioOperation` — операция/сделка по счёту
  - `PortfolioPeriodCalculator` — чистый расчёт денежных потоков и Modified Dietz
  - `InvestmentPlanCalculator` — сценарный прогноз сложного процента и расписание взносов
  - `RealizedTradeProfitCalculator` — FIFO результат продажи, включая распределение купонов по удерживаемому количеству
  - `IPortfolioHistoryRepository` — контракт истории стоимости
  - `IInvestmentPlanRepository` — контракт сохранения плана
  - `BondItem` — модель облигации с купонной информацией
  - `IPortfolioService` — интерфейс для работы с портфелем
  - `ITokenProvider` — интерфейс для работы с токеном API

- **Infrastructure**:
  - `TinkoffApiService` — реализация IPortfolioService через Tinkoff Invest API
  - `EnvironmentTokenProvider` — хранение токена в переменных окружения Windows

- **App (WPF)**:
  - `MainViewModel` — загрузка/фильтрация портфеля, встроенная аналитика и фоновый воркер API
  - `PortfolioPeriodAnalyticsViewModel` — выбранный период, KPI, список операций и график стоимости
  - `InvestmentPlanViewModel` — редактирование и план-факт сверка инвестиционного сценария
  - `PortfolioItemViewModel` — ViewModel для строки портфеля
  - `CouponHistogramViewModel` — прогноз купонов и сегменты для интерактивных подсказок
  - `PortfolioAnalyticsViewModel` — стоимость, результат, доходность, НКД, купонный поток и структура портфеля

## Установка и настройка

### Требования

- Windows 10/11
- .NET 9 SDK или .NET 9 Runtime
- Брокерский счёт Тинькофф с доступом к API

### Настройка токена Tinkoff

1. Получите токен для Tinkoff Invest API:
   - В личном кабинете Тинькофф: https://www.tinkoff.ru/invest/
   - Настройки → API → Создать новый токен
   - Выберите права: `read` (достаточно для чтения портфеля)

2. Установите токен в переменную окружения Windows:

```cmd
setx BOND_ANALYTICS_TOKEN "ваш_токен_здесь"
```

Или через PowerShell:

```powershell
[Environment]::SetEnvironmentVariable("BOND_ANALYTICS_TOKEN", "ваш_токен_здесь", "User")
```

3. Перезапустите приложение (или перезагрузите сессию для применения переменной окружения).

### Сборка и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/BondAnalytics.App.git
cd BondAnalytics.App

# Восстановите пакеты
dotnet restore

# Соберите проект
dotnet build -c Release

# Запустите приложение
dotnet run --project BondAnalytics.App
```

Или откройте `BondAnalytics.sln` в Visual Studio и запустите проект `BondAnalytics.App`.

### Сборка Android-приложения

Установите workload .NET MAUI и Android SDK, затем укажите путь к SDK, если он не обнаружен автоматически. Для создания автономного Release APK (не Android App Bundle) выполните:

```powershell
dotnet publish BondAnalytics.Mobile\BondAnalytics.Mobile.csproj -f net10.0-android -c Release `
  -p:AndroidPackageFormat=apk `
  -p:EmbedAssembliesIntoApk=true `
  -p:AndroidSdkDirectory=D:\Android\Sdk
```

APK создаётся в `BondAnalytics.Mobile\bin\Release\net10.0-android` или в его подкаталоге `publish` (зависит от версии Android workload). В APK включены приложение и .NET runtime, поэтому его можно скопировать на совместимое Android-устройство и установить без загрузки runtime или дополнительных файлов приложения. APK предназначен для установки напрямую; для публикации в Google Play используйте AAB.

## Использование

1. **Загрузка портфеля**: При запуске приложение автоматически загружает список облигаций из вашего счёта. Цены и все вычисляемые поля обновляются автоматически в соответствии с рынком.

   <img width="1171" height="580" alt="image" src="https://github.com/user-attachments/assets/c03df0a0-694a-4d83-a8e7-ada1d1c0c151" />


2. **Фильтрация**: Используйте выпадающий список для фильтрации:
   - Все — все облигации
   - ОФЗ — только государственные облигации
   - Корпоративные — только корпоративные облигации

3. **Графики**: На вкладке «Графики» доступны купонные выплаты, стоимость и результат позиций, купонная доходность, НКД, ожидаемые купоны и структура портфеля.
4. **Аналитика счёта**: Откройте одноимённую вкладку, выберите период или даты. Приложение загрузит операции и сделки через T-Invest API, посчитает денежные потоки и доходность, покажет стоимость портфеля на графике и отметит пополнения/выводы.
5. **План инвестиций**: Настройте дату и горизонт, цель, стартовый капитал, размер и частоту взносов, темп их повышения, рост цены, купонную доходность, реинвестирование, налог, комиссии и инфляцию. График и план-факт расписание пересчитываются при изменении параметров; нажмите «Сохранить / обновить план», чтобы он пережил перезапуск.

   - Зелёный — прибыль
   - Красный — убыток

## Особенности реализации

- **Потоковые данные**: Приложение подписывается на потоковые котировки через gRPC-стрим T-Invest API. Для облигаций котировка переводится из процентов от номинала, для фондов и акций цена используется напрямую.
- **Купонный прогноз**: Строится на основе ближайшей даты выплаты и частоты купонов. Выплаты группируются по месяцам, stacking отображает вклад каждого инструмента.
- **НКД**: API запрашивается в рублях; НКД на одну бумагу умножается на количество бумаг в позиции, без умножения на размер лота.
- **Фоновый воркер**: Котировки обновляются через поток API, состав портфеля перепроверяется каждые 10 минут и по ручному запросу. При сбое повторные попытки идут через 5 секунд, затем интервал удваивается до максимума в 5 минут.
- **Статус подключения**: Отдельно показывает состояние API, время последнего обновления портфеля и последней рыночной цены.
- **Периодная доходность**: Используется Modified Dietz с весом денежных потоков по дате. Доходность показывается только при наличии снимков стоимости на границах периода; история начинает накапливаться после первого запуска и хранится в `%LOCALAPPDATA%\BondAnalytics\portfolio-history.db`.
- **Калькулятор плана**: Сценарий является предположением, а не обещанием доходности. Рост цены, купонная доходность, налог, комиссия и инфляция задаются отдельно; купон реинвестируется или учитывается как выплаченный денежный поток.
- **Результат продажи**: Сумма по цене считается как цена продажи минус цена покупки для проданного количества по FIFO. Вариант «с купонами» добавляет купоны, полученные между соответствующей покупкой и продажей. Комиссии, налоги и НКД сделки в эти две цифры не включены; для продаж без найденной истории покупки показывается `н/д`.
- **Повторное подключение**: При сетевой ошибке приложение показывает понятный статус на русском и увеличивает задержку между запросами от 5 секунд до 5 минут.
- **Безопасность**: Токен API не хранится в репозитории, используется только переменная окружения пользователя.
- **Журналирование**: События и ошибки приложения записываются в `%LOCALAPPDATA%\BondAnalytics\Logs` с ежедневной ротацией и хранением 14 файлов. Токен в логи не записывается.
- **Обработка ошибок**: При отсутствии данных для гистограммы отображается информационное сообщение.
